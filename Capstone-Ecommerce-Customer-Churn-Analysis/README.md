# 🛒 E-Commerce Customer Churn Analysis

---

# 📌 Project Overview

This capstone project analyzes customer churn behavior in an e-commerce business using MySQL.

The project focuses on identifying churn patterns, customer behavior, payment preferences, satisfaction levels, and business insights using SQL analytics techniques.

---

# 🎯 Business Problem

E-commerce businesses face challenges in retaining customers and reducing churn.

This project helps analyze:
- Customer attrition patterns
- Preferred payment methods
- Customer satisfaction trends
- Cashback and coupon behavior
- Customer ordering patterns
